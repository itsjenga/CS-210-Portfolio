# CS-210-Portfolio
CS 210 portfolio project and reflection

## Corner Grocer Grocery Tracker

### Project Summary

The Corner Grocer program reads grocery items from a file and keeps track of how often each item appears. It lets the user look up an item, view the item frequencies, and see a simple histogram. The program also saves frequency information to a file.

### What I Did Well

I separated the program into different files for the main program and the `GroceryTracker` class. I also used comments to explain what the functions do. This helped me keep the code organized and made it easier to understand each part.

### What I Could Improve

I could improve the program by adding clearer messages when a file cannot be opened or saved. I could also make item searches ignore capitalization, so searching for an item works even if the user types it differently. These changes would make the program more reliable and easier to use.

### Challenges and Resources

Working with files was one of the more challenging parts of this project. I had to make sure the program could find the input file and save the frequency information correctly. I worked through the problem by checking my file names and paths and reviewing the code. Visual Studio, the course materials, ZyBooks, and instructor feedback are resources I can use for future projects.

### Transferable Skills

This project gave me more practice with C++, classes, functions, maps, file input and output, and debugging. These skills will help me with future projects that need to organize information, read from files, or save results.

### Maintainability, Readability, and Adaptability

I used clear function names, comments, and separate files for the class declaration and implementation. This makes the program easier to read and update. The program could also be adapted to track different items by changing the input data.
